# Product Requirements Document: 浮窗截图与按键面板

**Version**: 1.4
**Date**: 2026-10-19
**Author**: Sarah (Product Owner)
**Quality Score**: 90/100

---

## Executive Summary

JASM 的游戏内浮窗（Overlay）目前承担「选角色 → 勾 Mod → 刷新换装 → 右键标记 NSFW」这一条审阅流水线。实际使用时还有两处动作仍在主窗口与游戏之间来回切换：

1. **截取游戏内预览图**：看到满意的效果后，要切出游戏、打开截图工具、框选、另存 —— 打断审阅节奏，且文件名与 Mod 容易对不上。
2. **触发 Mod 自己的按键映射**：每个 Mod 的 ini 绑定（换形态、开关部件等）只在主窗口详情页里有徽章，游戏内想按一下得先切出去找。

本 PRD 定义在浮窗上新增**区域内截图（可复用上次区域）**与**当前 Mod 按键面板（点击即发送到游戏）**两个功能。两者共用「唯一勾选的 Mod」这一判定对象，目标是把审阅、截图、触发按键都收在游戏内的同一块浮窗里。

本功能仅服务于**老线的本地自用场景**（`qsy123-coder/JASM` 老仓库，不随发布会通道分发），且浮窗本身只为**鸣潮**创建。两个功能同一批交付。

## Problem Statement

**Current Situation**

- 浮窗能换装，但截不了图。游戏内看到效果后必须离开游戏完成截图与另存，一次审阅会被打断多次。
- 每次截图都要重新框选，同样的构图反复框，效率低且容易框歪。
- Mod 的 ini 按键绑定只存在于主窗口详情页；浮窗里看不到，也无法在游戏内触发。
- 截图文件名与 Mod 的对应关系靠手工维护，容易错名、覆盖或找不到。

**Proposed Solution**

- 浮窗内提供「框选截图」与「按上次区域截图」两种入口；截图以当前**唯一勾选**的 Mod 的显示名命名，保存为 PNG 到可配置的输出目录。**截图不修改 Mod 封面**，封面始终沿用用户原来的设置。
- 全局热键 `Ctrl+Alt+S` 在游戏内直接按上次区域截图（被占用时自动回退），无需唤出浮窗。
- 在**当前唯一勾选的那一行 Mod 下方**提供可折叠的按键面板，显示该 Mod 的 ini 绑定；点击徽章即通过现有送键通道发往游戏。面板跟着勾选行走，不是浮窗底部的全局面板。

**Business Impact**

- 单次审阅从「切出游戏 × N 次」降为「热键一次」。
- 截图与 Mod 的对应关系由程序保证，不再依赖手工命名。
- 按键触达从「切出游戏 → 找详情页 → 点徽章」降为「浮窗内一下」。

## Success Metrics

**Primary KPIs（本地自用，以验收标准衡量）**

- 区域已记忆时，从按下 `Ctrl+Alt+S` 到文件落盘 ≤ 2 秒（不含游戏渲染与首次 JIT）。
- 连续截取 20 张不同 Mod，文件名与目标 Mod 对应正确率 100%，无覆盖、无非法字符导致的保存失败。
- 截图完成后，Mod 的封面与封面文件保持原样（截图不参与封面策略）。
- 单选模式下从任意入口导入新 Mod 后，浮窗里仍然只有原来那一件处于勾选状态。
- 勾选一个 Mod 后 ≤ 500ms 内按键面板显示该 Mod 的全部 ini 绑定。
- 点击按键徽章后，游戏在正常（提权助手可用）场景下响应；失败必须给出可行动的原因。

**Validation**

- 实机（Windows 11 + 鸣潮）验收，覆盖窗口化、无边框全屏、独占全屏三种显示模式。
- 回归检查：浮窗唤出/收起、NSFW 右键标记、勾选刷新、拖拽安装均不受影响。

## User Personas

### Primary: 个人 Mod 审阅者 / 作者

- **Role**: 在自己机器上逐件试用鸣潮 Mod、挑出要保留/下架/发布的条目。
- **Goals**: 快速切换效果、留下预览图、顺手触发 Mod 内的开关按键。
- **Pain Points**: 反复切出游戏；截图命名混乱；按键入口不在手边。
- **Technical Level**: 高级（能自行构建、读日志、改配置）。

单人使用，无多用户与权限隔离需求。

## User Stories & Acceptance Criteria

### Story 1: 框选并保存截图

**As a** 审阅者
**I want to** 在浮窗里框一块区域并截图
**So that** 不用离开游戏就能留下当前效果的预览图

**Acceptance Criteria:**

- [ ] 浮窗上存在「框选截图」入口；点击后浮窗先隐藏，屏幕出现半透明遮罩。
- [ ] 按住鼠标拖出矩形，松手立即截图并进入保存流程；按 `Esc` 取消，浮窗恢复原显隐状态。
- [ ] 截图不包含浮窗、框选遮罩与鼠标指针。
- [ ] 区域以物理像素、虚拟屏幕坐标记录；多显示器与不同 DPI 下复用仍然正确。
- [ ] 区域过小（宽或高 < 8 像素）时视为误操作，取消并提示。

### Story 2: 复用上次区域快速截图

**As a** 审阅者
**I want to** 一键按上次的构图再截一张
**So that** 同一角度连测多个 Mod 时不用反复框选

**Acceptance Criteria:**

- [ ] 浮窗上存在「按上次区域截」按钮；点击后不显示遮罩，直接按记忆区域截图。
- [ ] 全局热键 `Ctrl+Alt+S` 在游戏前台、浮窗隐藏时同样可用。
- [ ] 热键被占用时按候选顺序自动回退（`Ctrl+Alt+S` → `Ctrl+Shift+S` → `F9`），并在浮窗提示实际生效的键；全部失败时按钮仍可用。
- [ ] 尚无记忆区域时，热键与按钮都转入「框选」流程。
- [ ] 记忆区域超出当前屏幕工作区（换分辨率/换显示器）时，先夹取到有效范围；完全无效则要求重新框选。
- [ ] 连按热键不会并发截图；上一张未完成时忽略后续触发。

### Story 3: 按当前勾选的 Mod 命名并保存

**As a** 审阅者
**I want to** 截图自动按 Mod 名保存
**So that** 文件与 Mod 的对应关系不需要手工维护，同时不碰我原来的封面

**Acceptance Criteria:**

- [ ] 截图目标 = 当前**唯一勾选**的 Mod；未勾选或多选勾选多件时，不允许截图并提示「请先勾选且只勾选一件 Mod」。
- [ ] 文件名取浮窗显示的 Mod 名（自定义名优先，否则去掉 `DISABLED_` 的文件夹名）。
- [ ] 非法文件名字符替换为 `_`；去掉首尾空格与点；长度上限 80 字符（保留扩展名）。
- [ ] 同名文件已存在时自动追加 `-2`、`-3`……不覆盖已有文件。
- [ ] 文件保存为 PNG，输出目录可配置；首次使用默认为 `图片\JASM\浮窗截图`。
- [ ] **不修改 Mod 的 `ImagePath`，不复制 / 覆盖 `.JASM_Cover.*`，也不发送封面变更消息**；截图只存在于输出目录。
- [ ] 如果输出目录与 Mod 文件夹相同，仍然只新增一张 PNG，不改任何封面文件。

### Story 4: 截图反馈

**As a** 审阅者
**I want to** 知道截图成功与否，但不被打断
**So that** 连续截图时节奏不被打断

**Acceptance Criteria:**

- [ ] 成功时浮窗恢复到截图前的显隐状态，并在浮窗内短暂显示「已保存：文件名」；不弹系统通知。
- [ ] 失败时显示可行动的原因（无唯一勾选、目录不可写、截图失败等），并保留记忆区域。
- [ ] 截图失败不得把浮窗留在隐藏状态。

### Story 5: 浮窗内查看并触发按键映射

**As a** 审阅者
**I want to** 在浮窗里看到当前 Mod 的所有 ini 按键绑定并点击发送
**So that** 不用切出游戏就能触发 Mod 内的开关

**Acceptance Criteria:**

- [ ] 面板显示当前唯一勾选 Mod 的 ini 绑定，解析复用 `ModIniKeyBindingParser.ParseAllKeyBindings`。
- [ ] 按 ini 文件分组，组可折叠；每行显示标签与按键徽章。
- [ ] 点击徽章调用 `IGameKeySender.SendKeyAsync(KeyCode, ModifierKeyCodes, 浮窗句柄)`，送完把前台交还浮窗。
- [ ] 成功静默；失败弹通知并给出原因（目标未配置 / 游戏未运行 / 提权 / 送键失败），文案与详情页徽章一致。
- [ ] 不可发送的条目（如鼠标按键无虚拟键码）保持禁用并显示为普通文本。
- [ ] 无绑定或未解析完成时给出明确状态，不显示空白面板。
- [ ] 切换唯一勾选的 Mod 或切换角色时，面板内容随之更新；解析在后台线程完成，不阻塞 UI。

### Story 6: 面板的展开与收起

**As a** 审阅者
**I want to** 按键面板贴在勾选的那一件 Mod 下面，并且能折叠
**So that** 「这一件有哪些按键」和 Mod 本身挨在一起看，不占浮窗底部的固定空间

**Acceptance Criteria:**

- [ ] 面板是**行内的**：挂在当前唯一勾选的那一行下面，不显示在浮窗底部，也不是全局面板。
- [ ] 勾选换到另一行时，面板跟着移到新行；原行不再显示。
- [ ] 目标行从「不显示面板」变为「显示」时默认展开；用户手动折叠后保持折叠，直到勾选换行 / 取消勾选。
- [ ] 行内的「按键映射」标题行可点击折叠 / 展开，箭头方向随状态变化。
- [ ] 浮窗尺寸保持不变；面板把列表项撑高，列表自身滚动，必要时把目标行滚进视野。
- [ ] 无唯一勾选时，所有行都不显示面板。

### Story 7: 列表首项贴顶

**As a** 审阅者
**I want to** 浮窗里的第一个 Mod 紧贴列表顶部
**So that** 不浪费纵向空间，也不像"上面还藏着一行"

**Acceptance Criteria:**

- [ ] 列表没有额外的顶部留白；第一行的容器紧贴列表可视区上沿（仅保留列表项自身的 2px 内边距）。
- [ ] 勾选 / 面板展开触发滚动时，目标行按 **Leading** 对齐顶到列表上沿，不按底部对齐。
- [ ] 搜索过滤后第一项同样贴顶。
- [ ] 行内按键面板展开不会把首行往下推出一段空白。

### Story 8: 单选模式下导入不制造多勾选

**As a** 审阅者
**I want to** 导入新 Mod 时不改变当前勾选
**So that** 单选模式始终只有一件生效，不会因为导入多出几件

**Acceptance Criteria:**

- [ ] 单选模式开启时，**任意导入路径**（浮窗拖入、主窗口拖入、安装向导、Mod 商店）安装的新 Mod 默认不勾选。
- [ ] 当前已勾选的 Mod 保持不变；导入前没有勾选时，导入后也没有（由用户自己勾）。
- [ ] 多选模式不受影响，按原行为处理新 Mod。
- [ ] 导入完成后浮窗列表正常刷新，但不会出现多件勾选。
- [ ] 该规则只作用于"导入产生的新 Mod"，不影响用户手动勾选 / 取消。

### Story 9: 浮窗大小档位

**As a** 审阅者
**I want to** 在浮窗标题栏切换小 / 中 / 大
**So that** 根据屏幕和 Mod 名长度调整可见空间

**Acceptance Criteria:**

- [ ] 三档尺寸（DIP）：小 `320×300`、中 `380×360`（默认，当前尺寸）、大 `460×480`。
- [ ] 标题栏有一个紧凑下拉框，显示当前档位；切换立即生效。
- [ ] 档位持久化（`OverlaySettings`），下次启动沿用。
- [ ] 切换后窗口位置夹回当前显示器工作区；Mod 列表与行内按键面板适配新尺寸。
- [ ] 换显示器 / 改缩放后档位仍然有效，位置按既有规则夹取。

### Story 10: 中键标记已看过

**As a** 审阅者
**I want to** 用鼠标中键把一行标成「已看过」，再点一次取消
**So that** 一轮审完时能一眼分出哪些已经看过，不用靠记忆

**Acceptance Criteria:**

- [ ] 在浮窗任意 Mod 行上按鼠标中键，切换该行的「已看过」状态；再按一次取消。
- [ ] 中键只动名单，不改 Mod 文件夹名、不碰 Mod 设置文件、不触发刷新。
- [ ] 已看过的行显示一个绿色对勾（带「已看过（中键标记 / 取消）」tooltip）。
- [ ] 「已看过」与右键的 NSFW 标记**互相独立**：同一件可以同时是两者，也可以只标一个。
- [ ] 标记写进 **Mod 自己的设置文件**（`.JASM_ModConfig.json` 的 `SeenAt` 时间戳），跟着 Mod 走。
- [ ] 主窗口角色画廊的 Mod 卡片显示「已看过」绿底角标；浮窗写完设置后主窗口即时更新。
- [ ] 旧版 `OverlaySeenMarks` 名单在启动时一次性迁移进对应 Mod 的 `SeenAt`；迁移后旧名单不再重放。
- [ ] 有标记时浮窗显示「已看过 N 个 · 中键可标记 / 取消」。
- [ ] 切换行/角色、重启 JASM 后标记仍然在。

### Story 11: 行尾「下一个」

**As a** 审阅者
**I want to** 在已勾选的行右边点一下「下一个」
**So that** 不用回勾选框那一列，就能一件件往下审

**Acceptance Criteria:**

- [ ] 单选模式下，当前勾选行的行尾显示「下一个」按钮；多选模式不显示。
- [ ] 点击后勾选列表里的下一行；当前行自动收起，并触发一次 F10 刷新（与手动勾选同一条路）。
- [ ] 最后一行的「下一个」按钮不显示（不循环回第一件）。
- [ ] 按钮跟着勾选行走：切到下一件后，按钮出现在新的当前行上。
- [ ] 搜索过滤后按**当前可见列表**的顺序取下一行。

## Functional Requirements

### Core Features

**Feature 1: 区域内截图**

- Description: **自动隐藏浮窗** → 全屏遮罩框选 → 立即截取屏幕对应区域 → 命名、保存。浮窗与框选遮罩都不得出现在截图里。
- User flow:
  1. 用户确认浮窗里**恰好一件** Mod 被勾选。
  2. 点「框选截图」/ 在无记忆区域时按 `Ctrl+Alt+S`。
  3. 浮窗隐藏，出现遮罩；拖框；松手。
  4. 系统截取该矩形 → 生成文件名 → 写入输出目录。
  5. 浮窗恢复**截图前**的显隐状态并显示「已保存：文件名」。
- Edge cases:
  - 无唯一勾选：拒绝并提示。
  - 输出目录不存在：尝试创建；创建失败则提示并保留区域。
  - 目录不可写 / 磁盘满：提示失败原因，区域保留。
  - 区域过小：视为取消。
  - 截图 API 返回空帧（典型为独占全屏）：提示截图失败，不写文件、不设封面、区域保留。
  - 截图前浮窗是隐藏的（热键触发）：截完保持隐藏，成功 / 失败走系统通知。
- Error handling: 所有失败均落日志（含区域坐标、目标 Mod、输出路径），界面只给可行动的一句话。任何失败路径都不得把浮窗留在隐藏状态。

**Feature 2: 快捷区域复用**

- Description: 记住最后一次成功框选的矩形（物理像素、虚拟屏幕坐标），提供按钮与全局热键两条快捷路径。
- User flow:
  - 有记忆区域：按钮或热键 → 直接截图 → 保存 → 反馈（浮窗按截图前状态恢复）。
  - 无记忆区域：转入框选流程。
- Edge cases:
  - 热键候选全部不可注册：浮窗内展示实际失败原因；按钮路径不受影响。
  - 分辨率/显示器变化：按工作区夹取；夹取后宽或高 < 8 像素则视为无效，要求重新框选。
  - 快速连按：串行化，进行中忽略新触发。
- Error handling: 同 Feature 1。

**Feature 3: 命名与落盘**

- Description: 文件名 = 浮窗显示名；PNG；重名自动加序号；**只写输出目录，不碰 Mod 封面**。
- User flow: 截图成功 → 清理文件名 → 选择不冲突路径 → 写文件 → 显示「已保存」。
- Edge cases:
  - Mod 名含 `\ / : * ? " < > |` 等非法字符：替换为 `_`。
  - Mod 名超长：截断到 80 字符。
  - 输出目录与 Mod 文件夹重合：只新增 PNG，不改 / 不覆盖 `.JASM_Cover.*`。
- Error handling: 写文件失败只报这一件事；不存在"封面写入失败"这条路径（本期不改封面）。

**Feature 4: 当前 Mod 按键面板**

- Description: 当前唯一勾选 Mod 的**行内**折叠面板，展示它的 ini 绑定并支持点击发送；面板跟着勾选行移动。
- User flow: 勾选 Mod → 面板出现在该行下方并展开 → 后台解析其 ini → 显示分组/徽章 → 点击徽章 → 送键 → 成功静默 / 失败通知。
- Edge cases:
  - Mod 无 ini / 无绑定：显示「此 Mod 无按键绑定」。
  - 解析失败：显示「读取按键绑定失败」，错误进日志。
  - 游戏未运行 / 未配置目标：沿用详情页的失败文案。
  - 游戏提权运行：走既有提权助手通道；助手不可用时提示更新 JASM，不劝用户以管理员运行 JASM。
  - 点击后前台与光标：送键后交还浮窗前台（与刷新路径一致），并沿用光标居中还原保护。
- Error handling: 解析失败不抛出到 UI 线程；送键失败弹通知，静默成功。

**Feature 5: 输出目录与热键配置**

- Description: 输出目录与截图热键在两个入口可查改。
- User flow:
  - 浮窗快捷入口：选择输出目录、查看/清除记忆区域、查看实际生效的截图热键。
  - 主程序设置页：完整设置（默认输出目录、清除记忆区域、热键候选说明；**不提供"截图后设封面"开关** —— 截图永远不改封面）。
- Edge cases:
  - 目录被删除：下次截图自动尝试创建。
  - 设置文件损坏：退化为默认输出目录与「未记忆区域」。
- Error handling: 设置读取失败不阻止浮窗启动（与 `OverlaySettings` 现有约定一致）。

**Feature 6: 单选模式导入一致性**

- Description: 单选模式开启时，**任意导入路径**安装的新 Mod 都不自动勾选；当前勾选保持不变。
- User flow: 导入 Mod → 安装 / 落盘完成 → 若单选模式开启，新 Mod 保持在未启用状态 → 浮窗刷新 → 当前勾选仍只有原来那一件。
- Edge cases:
  - 导入前没有勾选：导入后仍然没有勾选（由用户自己勾）。
  - 一次批量导入多个：全部不启用。
  - 多选模式：保持原行为，不受影响。
  - 导入失败：不影响现有勾选。
- Error handling: 若新 Mod 无法保持未启用（只读 / 权限），发一条通知说明，但**不得**改动当前勾选的 Mod。

**Feature 7: 浮窗大小档位**

- Description: 三档固定尺寸 + 标题栏紧凑下拉框 + 持久化。
- User flow: 标题栏选择小 / 中 / 大 → 窗口按对应 DIP 尺寸调整 → 位置夹回工作区 → 记住选择。
- Edge cases:
  - 窗口比当前工作区大：按 `OverlayPlacement` 夹取，允许贴边。
  - 行内按键面板展开后超出可视高度：由 Mod 列表内部滚动消化，不改变窗口尺寸。
  - 设置文件缺失 / 损坏：退回中档（380×360）。
- Error handling: 尺寸切换失败不阻塞浮窗使用；保留原尺寸并记日志。

**Feature 8: 中键「已看过」标记**

- Description: 鼠标中键切换一行 Mod 的已看过记号，写进 Mod 自己的设置（`SeenAt`）；浮窗显示绿色对勾，主窗口画廊卡片显示绿色「已看过」角标。
- User flow: 中键点行 → 通过 `ModSettingsService` 写入 / 清空 `SeenAt` → 行上显示/隐藏绿勾 → 发 `ModChangedMessage` 让画廊角标同步 → 浮窗计数行更新。
- Edge cases:
  - 中键点在勾选框 / 缩略图 / 名字上：都算这一行。
  - Mod 设置写入失败：回滚行上的记号并显示失败提示（数据源是 Mod 设置，不能只改界面）。
  - 旧 `OverlaySeenMarks` 名单存在：启动时一次性迁移；`Migrated=true` 后不再重放，避免用户取消后被旧名单重新标上。
  - Mod 已删除 / 找不到：迁移时跳过。
- Error handling: 写设置失败记日志并在浮窗状态行提示；不触发刷新。

**Feature 9: 行尾「下一个」**

- Description: 单选模式下在勾选行行尾显示「下一个」，点击勾选当前可见列表的下一件。
- User flow: 点「下一个」→ 勾上下一件 → 当前件自动收起 → F10 刷新 → 按钮移到新的当前行。
- Edge cases:
  - 当前行是最后一行：不显示按钮。
  - 列表被搜索过滤：下一件按可见列表取，不跳到被过滤掉的 Mod。
  - 多选模式：按钮不显示。
  - 切换失败：沿用勾选失败的状态行提示，不把按钮留在错误状态。
- Error handling: 与手动勾选完全同一路径，沿用其失败处理。

### Out of Scope

- 视频录制、连拍、定时截图。
- 截图标注/裁剪编辑器、上传或分享。
- 多选模式下汇总多个 Mod 的截图或按键。
- 显示或发送游戏/XXMI 的全局按键（只做 Mod 自己的 ini 绑定）。
- 修改 ini 中的按键绑定（本期只读显示 + 发送）。
- 截图后自动设置 / 替换 Mod 封面（本期明确不做）。
- 自由拖拽改变浮窗大小（只做三档预设）。
- 多用户、权限、云同步。
- 除鸣潮外的其它游戏（浮窗本身仍只为鸣潮创建）。

## Technical Constraints

### Performance

- 勾选 Mod 后按键面板内容 ≤ 500ms 出现；ini 解析在后台线程，按 Mod 缓存，重复切换不重复扫盘。
- 截图路径中 UI 线程只做显隐与反馈；编码与写盘在后台线程。
- 截图串行化；进行中忽略重复触发。

### Security

- 仅写入用户显式配置的本地目录；不访问网络。
- 送键沿用既有 `KeyChordGuard` 危险组合键拦截与 UIPI 处理，不新增注入路径。
- 日志中不输出用户目录以外的敏感信息。

### Integration

- **截图捕获**: Windows.Graphics.Capture（通过 `IGraphicsCaptureItemInterop` 直接取窗口/显示器，避免每次弹系统选择器）或等价方案；需新增 CsWin32 `NativeMethods.txt` 条目。**截图前必须隐藏浮窗；框选遮罩本身也不得进入截图**。截完按截图前的显隐恢复。
- **热键**: 扩展 `OverlayHotkeyRegistrar`，新增「截图」动作，候选 `Ctrl+Alt+S` → `Ctrl+Shift+S` → `F9`；该热键需在浮窗隐藏、游戏前台时仍然注册（与唤出热键同一生命周期），换游戏或退出时注销。
- **送键**: 复用 `IGameKeySender` / `ElevatorService`；徽章点击时传浮窗 HWND 以交还前台，行为与 `OverlayRefreshCoordinator` 一致。
- **按键解析**: 复用 `ModIniKeyBindingParser.ParseAllKeyBindings(mod.FullPath)` 与 `ModIniKeyBindingEntry`。
- **封面**: 截图路径**不调用** `ModSettingsService`，不写 `ImagePath`，不复制 / 删除 `.JASM_Cover.*`。
- **导入一致性**: 单选模式开启时，安装完成的新 Mod 必须保持未启用。优先在安装入口（`ModInstallerService` / 拖拽安装服务）统一处理，避免只改浮窗一条路。
- **列表贴顶**: ListView 去掉额外顶部留白；滚动定位使用 `ScrollIntoView(item, ScrollIntoViewAlignment.Leading)`。
- **尺寸档位**: 扩展 `OverlaySettings`（App 作用域）保存档位（Small/Medium/Large）；窗口尺寸仍以 DIP 设置，位置用 `OverlayPlacement` 夹取。
- **设置持久化**: 扩展 `OverlaySettings`（App 作用域）：输出目录、最后截图区域（X/Y/宽/高，物理像素）、尺寸档位、截图热键候选状态、按键面板手动折叠状态。Debug 构建写入 `LocalAppSettings_Debug.json`。

### Technology Stack

- .NET 9 / WinUI 3 / Windows App SDK 1.7；老线本地构建（Debug）。
- 仅 Windows 11；目标游戏为鸣潮（提权运行）。

## MVP Scope & Phasing

### Phase 0: 技术验证（必须先做）

- 在鸣潮窗口化、无边框全屏、独占全屏三种模式下验证截图 API 不返回黑帧。
- 验证截图前隐藏浮窗后确实不把浮窗与遮罩拍进去。
- 验证 `Ctrl+Alt+S` 在游戏前台时能被全局热键捕获（含提权游戏）。
- 验证点击徽章送键后前台能交还浮窗（沿用既有助手通道）。

**结论若为独占全屏不可截**：MVP 退化为「窗口化/无边框全屏可用」，并在浮窗与 PRD 中明确提示；是否投入 DXGI 桌面复制另议。

### Phase 1: MVP（首批交付）

- 框选截图 + 记忆区域 + 按钮/热键快捷截图；截图前自动隐藏浮窗，截完恢复原显隐。
- 命名、PNG、重名序号、输出目录；**不改封面**。
- 当前 Mod ini 按键面板（行内、分组、折叠、点击发送、失败通知）。
- 列表首项贴顶；单选模式下任意导入不改变当前勾选。
- 浮窗小 / 中 / 大三档尺寸 + 标题栏下拉框 + 持久化。
- 设置入口两处：浮窗快捷入口 + 主程序设置页。

### Phase 2: Enhancements（后续）

- 自定义尺寸（输入宽高或拖边缘）。
- 面板支持按 ini 文件记忆折叠状态。
- 截图缓存缩略图与快速查看。
- 按键面板支持搜索/过滤。
- 多选模式下为每件 Mod 单独截图（需先定义命名与目录规则）。

### Future Considerations

- 将「唯一勾选」扩展为「为每件勾选的 Mod 依次截图」的批量审阅流程。
- 截图直接写入 Mod 文件夹并随 Mod 一起导出。

## Risk Assessment

| Risk | Probability | Impact | Mitigation Strategy |
|------|------------|--------|---------------------|
| 独占全屏下截图返回黑帧 | High | High | Phase 0 先验证；不可行时退化为窗口化/无边框并明确提示，不阻塞其它功能 |
| 用户正在全屏时框选遮罩不可见 | Med | High | Phase 0 同时验证；若不可见则提供「记住区域 + 热键」作为主路径，框选需切窗口化 |
| 全局热键与游戏/其它软件冲突 | Med | Low | 候选回退 + 界面显示实际生效键；按钮路径始终可用 |
| 文件名校验不完整导致保存失败 | Low | Med | 统一清洗函数 + 单测覆盖非法字符、超长、重名 |
| 送键因前台锁失败 | Med | Med | 复用既有交还前台与光标还原逻辑；失败如实提示 |
| 面板解析阻塞 UI | Low | Med | 后台解析 + 按 Mod 缓存 + 加载态 |
| 行内面板展开后目标行落在列表可视区外 | Med | Low | 面板换行时主动 `ScrollIntoView(..., Leading)`；浮窗尺寸不变，由列表滚动消化高度 |
| 有导入路径绕过"新 Mod 不启用"规则 | Med | Med | 在安装服务层统一处理，并在浮窗列表刷新时回归验证所有导入入口 |
| 尺寸档位切换后窗口超出工作区 | Low | Low | 切换后立即用 `OverlayPlacement` 夹取；越界时贴边而不是移出屏幕 |

## Appendix

### Glossary

- **唯一勾选**：当前角色下 `IsEnabled == true` 的 Mod 恰好一件。单选模式天然满足；多选模式要求用户先取消其它勾选。
- **记忆区域**：最后一次成功框选并完成保存的矩形，物理像素、虚拟屏幕坐标。
- **显示名**：浮窗列表上看到的名称，即 `CustomName` 优先、否则去掉 `DISABLED_` 的文件夹名。
- **按键映射**：Mod ini 中非 KeySwap 段落的按键绑定，由 `ModIniKeyBindingParser` 解析。
- **尺寸档位**：小 `320×300` / 中 `380×360` / 大 `460×480`（DIP），由标题栏下拉框切换并持久化。
