# 游戏内菜单汉化与数值序号 PRD

**Version**: 1.0
**Date**: 2026-11-08
**Status**: 待确认
**相关**：`docs/mod-ingame-menu-prd.md`、`docs/mod-ingame-menu-debug-log.md`

---

## 背景与问题

游戏内 Mod 切换菜单的行名称来自 mod ini 的 `[Key*]` 注释或段落名，绝大多数是英文（`Skirt`、`Dress`、`Hair Acc`…）。项目里已经有一份中英对照表 `Core/Entities/Mods/Helpers/KeyBindingLabelLocalizer.cs`，目前只用于「按键映射」面板，菜单没有接。

同时，菜单的当前值只显示原始值（`0`、`1`、`2`），用户看不出「这是第几个、一共几个」。参考菜单（《心·绀星绮愿》GUI）在每行右下角显示 `1/4`、`2/4` 这种「序号/总数」。

## 目标 / 非目标

### 目标

- 菜单行名称复用现有 `KeyBindingLabelLocalizer` 词表翻译成中文；查不到时保留英文原文。
- 每行右下角显示 `当前序号/总数`（1 起算，如 `1/3`、`2/3`、`3/3`），右对齐，仿参考菜单。
- 扫描用户下载的 100+ 个 mod，把出现频率高的未翻译英文标签去重后补进词表。

### 非目标

- 不翻译「值」本身（`Off`/`On` 这类值文本）、不翻译按键提示（`Alt+R`）。
- 不翻译作者自定义的不透明变体 ID（`SK_A`、`TS1`、`1` 等）；沿用 `KeyBindingLabelLocalizer` 现有规则：拿不准就保留原文。
- 不修改任何作者 ini；所有翻译只影响 JASM 生成的菜单显示。

## 用户故事

**作为** 鸣潮 Mod 玩家
**我想要** 菜单行显示中文，并看到「第几个/共几个」
**以便** 不用猜英文标签，也能知道当前循环到哪个值

## 方案设计

### 1. 行名称汉化（复用现有词表）

- 位置：`ModIniToggleParser.Flush` 生成 `ModIniToggleRow.Label` 时，改为
  `KeyBindingLabelLocalizer.Localize(BuildLabel(priorComment, header))`。
- 标签来源优先级不变：段落上方注释 → 去 `Key` 前缀的段落名。
- 已含中文的标签原样保留；词表未命中 → 原样英文。
- manifest 里新增 `rawLabel` 字段保留原始标签，便于排查（`label` 存翻译后的显示值）。

### 2. 数值显示 `序号/总数`

- 值纹理不再渲染原始值（`0`/`1`/`2`），改为 `"{valueIndex + 1}/{values.Count}"`。
- 位置：行右下角，右对齐；参考素材主题下：
  - 值纹理宽度 = `LabelWidthFor`（200）
  - `x = rowWidth - 值宽 - 32`，`y = rowY + 30`
  - 纹理渲染用 `TextAlign.Right`，让 `1/3` 贴住行右侧
- 按键提示保持在右上角（`y + 4`），与值分两行，不重叠。
- 非连续值（`4,8,9`）按**位置**显示 `1/3`、`2/3`、`3/3`，不显示原始值。

### 3. 词表扩充流程（100+ mod）

新增一个临时扫描工具（`Tools` 或独立脚本，不进入主程序）：

1. 输入一个 mods 根目录，递归扫描所有 `*.ini`（排除 `JASM_Menu.ini`）。
2. 提取 `[Key*]` 段落名 + 紧贴段落上方的注释。
3. 归一化（`KeyBindingLabelLocalizer.Normalize` 同款：去分隔符、小写）后去重。
4. 过滤：已含中文、纯数字、已能翻译的（`Localize(x) != x`）不输出。
5. 输出 `untranslated-labels.tsv`：`标签 \t 出现次数 \t 示例段落`。
6. 人工/模型翻译后，按「整串精确 / 英文单词 / 拼音」三类补进 `KeyBindingLabelLocalizer`。

### 为什么不用 resw 资源

mod 段落名是作者自定字符串，数量动态增长，无法提前写进 `.resw`；现有 `KeyBindingLabelLocalizer` 就是为此设计的代码内词表，复用成本最低。

## 数据与接口变更

- `ModIniToggleRow.Label`：内容语义变为「本地化后的显示标签」。
- `JASM_Menu/manifest.json`：新增 `rawLabel`（不破坏现有字段）。
- `KeyBindingLabelLocalizer`：只增词，不改 `Localize` 算法。
- 生成器版本 +1，旧菜单在批量补齐时自动重建。

## 边界与异常

| 场景 | 行为 |
|---|---|
| 标签已是中文 | 原样保留 |
| 词表未命中 | 保留英文原文 |
| 标签是作者变体 ID（`SK_A`/`TS1`） | 保留原文，不猜 |
| 注释是一整句英文 | 逐词翻译能中的部分，剩余英文保留（与按键面板一致） |
| 值只有一个 | 显示 `1/1`，不可点击 |
| 值非连续（4,8,9） | 按位置显示 `1/3`、`2/3`、`3/3` |
| 旧菜单 | 版本门控自动重建 |

## 验收标准

- [ ] 菜单行名称对词表命中的标签显示中文；未命中保持英文。
- [ ] 每行右下角显示 `1/N`、`2/N`…，右对齐，与参考截图一致。
- [ ] 非连续值按位置显示，不显示原始值。
- [ ] manifest 同时保留 `label`（中文）与 `rawLabel`（原文）。
- [ ] 扫描工具能对 100+ mod 去重输出未翻译标签，不重复、不把中文/数字当英文。
- [ ] 单测覆盖：标签本地化接线、值文本/对齐、扫描去重。

## 测试计划

### 单测

- `ModIniToggleParser`：`[KeyShoes]` → `鞋子`；未知标签保持英文；中文标签不变。
- `InGameMenuIniBuilder`：值纹理文本为 `1/3`、`2/3`；参考主题下 `TextAlign.Right` 与右下角坐标。
- 扫描工具：同一标签跨文件出现只输出一次，计数正确。

### 实机

- 重建三份菜单，冷启动截图确认中文行名 + 右下角 `1/N`。
- 抽取一个多值行（如 iuno 的 shoes 6 值）确认显示 `1/6`…`6/6`。

## 分期

- **P2（拿到 mod 根目录后）**：扫描 100+ mod，去重、翻译、扩充词表，再重建。
